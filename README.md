# Project Description

CryptoLabX is a modular cryptography toolkit developed as part of the Cryptography Laboratory course.

The purpose of this project is to build a reusable software framework that will be expanded throughout the semester with different cryptographic algorithms, attacks, mathematical utilities and analysis tools.

Currently this project contains the basic project structure, menu-driven interface, file analysis module and logging system.
